            В Воронеже некоммерческим партнерством "Общественное благополучие Воронежа" создана Социальная сеть Воронежа.

            В Социальной сети можно неограниченно высказывать мнения по любым вопросам, размещать информацию, добавлять файлы распространенных форматов.

            Социальная сеть Воронежа создана для повышения благополучия участников сети, чьей составной частью является открытость информации, основанной на свободе мыслей и слова.
